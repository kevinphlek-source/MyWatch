# Mes montres

Application iPhone installable (PWA) : collection, montres recherchées, catalogue de plus de 300 modèles, rareté et vue 3D.

- Vue 3D réaliste (three.js) : boîtier, lunette, verre, index en relief, bracelet modélisés ; les aiguilles donnent l'heure réelle.
- Vignettes « photo studio » calculées en 3D sur le téléphone puis gardées en cache.
- Catalogue avec tri, filtres et fiche détaillée de chaque modèle.
- Fonctionne hors ligne une fois ouverte. Données et photos stockées sur le téléphone : pensez à « Exporter une sauvegarde » de temps en temps.

Installation sur iPhone : ouvrir le lien dans Safari, puis Partager, puis « Sur l'écran d'accueil ».
